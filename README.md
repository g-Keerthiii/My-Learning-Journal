# My Learning Journal

I’m using this repository to document the things I study by building small, hands-on experiments instead of just reading about them. The goal is simple: if I can explain a concept clearly after struggling with it, I probably actually understand it.

Most entries live in [journals](journals), and some of them point to small companion examples in [code](code). I try to keep the notes honest, slightly imperfect, and specific enough that future me can retrace the actual learning process.

## Learning Philosophy

I learn best when I make the idea concrete. That usually means sketching a mental model, writing a tiny prototype, breaking it on purpose, and then fixing the mistake until the behavior feels obvious. I’m not trying to sound polished here. I’m trying to sound like someone who was genuinely thinking through the problem in real time.

## What’s Inside

Each entry includes:

- why I picked the topic that day
- my own explanation of the concept
- a small code example or a link to a companion file
- one real thing that clicked
- one thing that confused me before it made sense
- a quick recap for future me

The code examples are not meant to be production-ready. They’re intentionally small so I can focus on the core idea instead of getting buried in framework details.
